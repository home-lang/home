# Recursive readdir baseline and pending native batch

Source checkpoint `26a428426d7402fbf486517c6135f32e56355610` appends already-relative descendant names directly, encodes each opened directory’s parent path once, and returns an allocation error while freeing copied paths when synchronous queue growth fails. The maintained integration control covers relative/normalized roots, Unicode, POSIX literal backslashes, Dirent parent paths, retained results and filesystem mutation freshness. Installed Node passes that control; Pickier, Zig formatting and diff checks pass. Native compilation and Home behavior are pending.

The diagnostic performs 200 synchronous recursive traversals of the same mirrored Node tree, counting 5,597 entries (5,208 files plus 389 directories; three file symlinks, no directory symlink cycle). Baseline string/Dirent traversal times were Home 36.00/95.52 seconds, installed Bun 1.4.2 42.14/53.71 seconds, and installed Node v26.10.0 13.12/4.18 seconds. Sorting is measured separately. This benchmark does not reproduce the entire original test’s sorting/deep-equality work, and no original-test pass credit is assigned. Installed Bun is not a rebuilt pinned-source binary.

The first build attempt failed because cleanup removed a derived object still referenced by cache metadata; clearing only that metadata repaired the dependency records. Two subsequent builds were stopped by the resource guard after repeated kernel process/footprint probe deadlines, without a compiler result. Their logs are retained. A later standalone process snapshot succeeded in 30 ms and returned 1,372 rows, showing the probe failure is intermittent. A fourth guarded build is queued behind another live Home job. It remains authoritative and has no result yet.

Twelve unchanged pinned originals are prepared, with byte identities recorded, but have not run against this batch. Original stress iteration counts and ten-second deadlines remain unchanged. No source, dependency SDK, credential or active-job cleanup was performed. Inactive derived object cleanup freed about 10.6 GB; subsequent cache metadata invalidation and rebuild costs are disclosed above.
