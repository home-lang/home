# Markdown HTML reference fixtures

The `expected` values were generated by actual Bun 1.4.4 `Bun.markdown.html`.
`fixtures.json` contains 217 text/options cases; `binary-fixtures.json` contains
all 256 single-byte inputs and nine multibyte/BOM/malformed UTF-8 cases. Home's
common smoke gate compares actual native rendering against these fixed values
on both engine backends. Do not regenerate expectations from Home.

`bun_markdown.mjs` also checks real subarray/DataView ranges, all typed-array
kinds, boxed strings, option errors, ordinary byte mutation and private option
serialization. `bun_markdown_buffer_limits.mjs` separately checks Home's explicit
refusal of reentrant detachment. That refusal is a documented limitation, not
native Bun buffer-pinning parity.
